## 候選 thesis（標題＝這句，不要「他認為」）

寫軟體變便宜了，瓶頸改成決定做什麼。

（口白可加「他認為」。）

矛盾：AI 讓 code 變快變便宜 ≠ 工程變便宜。成品／技術債仍貴；「做 agent」也不是起點。

## 章（五章，不是訪談年表）

1. **寫規格變容易，難的是規格本身**  
   Ng ~5:26–6:37。spec→code 變容易；瓶頸是決定做什麼、寫清楚要什麼。AI coding 讓建造變便宜，反而把瓶頸推到選題。

2. **工程師要會繞產品迴圈**  
   Ng ~5:53–7:00（寫碼→給使用者看→改構想）。可補 golden-age／building blocks ~2:38–3:35 若秒數不夠。省略 Eng:PM 比例閒聊。

3. **生成的 code 便宜，完工的 code 不便宜**  
   Moroney ~50:16–53:14。每次做東西都欠債。目標清楚才借「房貸」不是「信用卡」。Finished / engineered code is not cheap。

4. **先問為什麼，不要先做 agent**  
   Moroney ~58:41–1:00:27。歐洲公司要「做 agent」；正確第一問是 Why。真正要的是業務員更有效率，那句話裡沒有 AI、沒有 agent。不要當 AI shill。

5. **Agent 是四步，不是工具箱**  
   ~1:02:15–1:03:56。intent → plan → tools → reflect。Trusted advisor 是拆這四步，不是揮手說 toolkit、省 20%。
